# CoForge 产品界面设计指导

适用范围：CoForge Web 工作台、对话、列表、设置和相关产品交互。这里约束设计判断，不规定所有页面套用同一种布局，也不要求借本次任务重做无关页面。

## 目录

- [1. 来源与优先级](sources-and-priority.md): 设计依据的来源与优先级：设计稿、Untitled UI 官方组件、本规范与 Token 的关系。
- [2. 先确定用户任务，再选布局](task-first-layout.md): 先确定用户任务再选布局；列表与详情的导航逻辑、手机页面的连续内容表面。
- [3. 说明按需出现，不默认铺满页面](progressive-disclosure.md): 说明文字按需出现：信息类型的默认呈现方式与帮助入口要求。
- [4. 用真实内容建立清晰层级](content-hierarchy.md): 用真实内容建立层级：每份信息一个位置、具体文案、保留数据的单位与不确定性。
- [5. 让组件承担重复决策](component-decisions.md): 让组件承担重复决策，以及加载、骨架、Toast 与保存反馈的样板。
- [5.1 空状态复用组件，但不混淆业务状态](empty-states.md): 空状态按场景决定内容、图形与操作的组合、布局适配与验收；Members 目录的空状态与卡片规则。
- [6. 渲染检查与反馈闭环](review-loop.md): 渲染检查清单、交互验收与改进规范的反馈闭环。
- [7. 组件：只用官方](official-components.md): 只用 Untitled UI 官方组件：安装、限定修补、可复制的演示模板、自写原语与 lint 豁免规则。
- [8. 页面骨架与密度](page-skeleton-and-density.md): 页面骨架、侧栏、页头、操作区光学对齐、密度与聊天消息流。
- [9. 字段展示：表单和长值用网格，短事实用列表](field-display.md): 字段展示的两种写法：表单和长值用字段网格，短事实用事实列表。
- [10. 信息层级与文字](text-hierarchy.md): 信息层级与文字：每个事实只出现一次、少写字。
- [11. 颜色、状态、排版与深色模式](color-status-typography.md): 颜色、品牌紫的使用位置、按钮与危险操作、状态徽章、排版与深色模式。
- [12. 尺寸单位：rem 与 px](sizing-units.md): 尺寸单位：影响排版和阅读的尺寸用 rem，细线用 px；例外范围与存量清单。
- [13. 反馈：toast 还是内联](toast-vs-inline.md): 反馈用 toast 还是内联：主流设计系统的共识与 CoForge 的应用。
- [参考](references.md): 外部参考链接及各自的参考用途。
